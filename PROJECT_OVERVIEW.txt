🎯 MAIN WORKFLOW
════════════════════════════════════════════════════════════════════════════════

1️⃣  PREPARE DATA
    ├─ Organize audio in characters/ directory
    └─ Run: python scripts/prepare_data.py
         ↓
    Creates train/val/test splits in data/splits/

2️⃣  TRAIN MODEL
    └─ Run: python scripts/train.py
         ↓
    Saves best_model.pt to models/

3️⃣  EVALUATE MODEL
    └─ Run: python scripts/evaluate.py
         ↓
    Generates metrics and visualizations in results/

4️⃣  MAKE PREDICTIONS (MAIN USAGE)
    ├─ Place audio files in new_samples/
    └─ Run: python scripts/predict.py --audio filename.wav
         ↓
    Outputs character predictions with confidence scores

⚙️  TECHNICAL SPECIFICATIONS
════════════════════════════════════════════════════════════════════════════════

Model Architecture:
  └─ wav2vec2-base (95M parameters)
      ├─ Pretrained on LibriSpeech (960 hours)
      ├─ Transfer learning with layer freezing
      └─ Custom classification head

Data Processing:
  ├─ Sample rate: 16,000 Hz
  ├─ Duration: 4-8 seconds per clip
  ├─ Augmentation: noise, time stretch, gain variation
  └─ Normalization: -3 dB target

Training Strategy:
  ├─ Optimizer: AdamW with weight decay
  ├─ Scheduler: Cosine annealing
  ├─ Regularization: Dropout, label smoothing, early stopping
  └─ Batch size: 16 (configurable)

Performance:
  ├─ Expected accuracy: 75-90% (depends on data)
  ├─ Training time: 1-3 hours (GPU)
  └─ Inference time: <1 second per file

🎯 WHAT YOU NEED TO DO
════════════════════════════════════════════════════════════════════════════════

1. Install dependencies:
   pip install -r requirements.txt

2. Collect audio data:
   - Extract 150-250 audio clips per character (4-8 seconds each)
   - Organize in characters/[character_name]/*.wav

3. Run the pipeline:
   python scripts/prepare_data.py   # Split data
   python scripts/train.py          # Train model (1-3 hours)
   python scripts/evaluate.py       # Evaluate performance

4. Make predictions:
   python scripts/predict.py --audio new_samples/your_clip.wav
